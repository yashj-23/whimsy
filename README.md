# Whimsy

A grimoire of small, strange experiments for when you're stuck or bored. One app for your MacBook and your phone, installed from a web address, working offline, with everything stored only on the device.

## Download

Mac and Android apps are on the [Releases page](https://github.com/yashj-23/whimsy/releases/latest):

- **Mac:** `Whimsy-…-Mac-AppleSilicon.dmg` (M-series chips) or `Whimsy-…-Mac-Intel.dmg`. Open it, drag Whimsy to Applications. The first launch needs System Settings › Privacy & Security › Open Anyway, because the app isn't notarized by Apple.
- **Android:** `Whimsy-….apk`. Open it on the phone and allow installing from that source.
- **iPhone:** install from the web address below (Safari › Share › Add to Home Screen).

To publish a new version, raise `version` in `apps/desktop/package.json` (and `APP_VERSION` in `js/constants.js`) and push to `main`. The workflow builds both apps and creates the release.

## Install it from the web

Whimsy has to be served from an `https://` address once. After that it is installed like an app and runs offline.

**MacBook (Safari, macOS Sonoma or later):** open the address, then File › Add to Dock. Whimsy gets its own window, Dock icon and Launchpad entry.
**MacBook (Chrome):** open the address, click the install icon at the right of the address bar.
**iPhone:** open the address in Safari, tap Share › Add to Home Screen.
**Android:** open the address in Chrome, menu › Install app.

Each installed copy keeps its own journal. To move a journal between devices: Settings › Back up on one, Settings › Restore on the other (AirDrop works well).

## Host it

Any static host works. The folder needs no build step.

- **GitHub Pages:** put these files in a public repository, then Settings › Pages › Deploy from branch › `main` / root. The address will be `https://<you>.github.io/<repo>/`.
- **Netlify Drop:** drag this folder onto https://app.netlify.com/drop.

After changing any file, run `node tools/build.mjs` so the offline cache updates. Installed apps then show "A new version of Whimsy is ready" with an Update button.

## Develop

```
python3 -m http.server 8765      # then open http://localhost:8765
npm test                          # engine and deck tests (Node 18+)
node tools/build.mjs              # regenerate sw.js after edits
```

## How it's put together

| Path | What it does |
|---|---|
| `js/deck.js` | All 125+ cards, with tags for category, snag, intent, weirdness, effort, time, place, needs and adaptations |
| `js/engine.js` | Picks a card: hard rules first (bans, comfort rules, time, energy, place), then a fallback ladder for soft preferences, then a weighted draw (75% by your ratings, 25% pure chance) |
| `js/dice.js` | World Dice: values from the clock, the date and built-in lists, fixed at the moment of the draw |
| `js/actions.js` | Everything that changes state: drawing, skipping, adapting, the timer, saving sessions, backup |
| `js/store.js` | IndexedDB storage, export, import and schema migrations |
| `js/screens/` | Home, card, running session, reflection, journal, settings |
| `css/app.css` | The look: painted light ground, glass panels, glowing color orbs, dark luminous accents |
| `sw.js` | Offline cache, generated by `tools/build.mjs` |
| `tests/` | Rules that must always hold, such as "a banned card never appears" and "chaos never breaks comfort rules" |
